NO ARDUINO IDE REQUIRED

Install Custom MPH HUD

Plug the ESP32 into this computer with a USB data cable, then press Install. The firmware is compiled in GitHub's cloud, not on your computer.

Use Chrome or Edge on a computer that supports Web Serial. This installer does not work from iPhone Safari. The installer must be opened from the HTTPS GitHub Pages site.

The installer will ask which serial device to use. Your pictured ESP32 uses a CP2102 USB-to-serial chip, so the port may appear with “CP210x” or “Silicon Labs” in its name.
